# Repository revisions for ACS Omega manuscript ao-2026-11833c (Reviewer 1)

This file maps each reviewer comment that concerns the public code to the change made in this repository. **None of the changes alter the reported results.** `results/al_results.json` and `results/fp_cache/*.npy` are unchanged; only labels, documentation, fallback code paths and figures were corrected.

## Major 1: GPR–EI framework vs. GCN branch

*Finding confirmed.* The handcrafted representations use GPR + EI. The GCN branch (`run_gcn_al_loop`) trains the network end-to-end and feeds its **MC-Dropout** mean and standard deviation into the same EI function. GCN embeddings are never passed to a GPR.

* The module docstring of `src/active_learning_benchmark_700dpi.py`, the README and `config/benchmark_config.json` now state this explicitly. The claim of a single "unified GPR + EI loop" has been removed.
* No code change was needed; the GCN implementation is unchanged.

## Major 2: Representations differ from their descriptions

*All points confirmed* by `src/verify_features.py` (output: `results/feature_provenance.json`). The reported results were produced from `data/features/*.csv`, generated by `notebooks/Active_Learning_Data_Generation.ipynb`:

| Item | Manuscript (original) | Features actually used | Old fallback code |
|---|---|---|---|
| Morgan | radius 2 | **radius 1**, 2048 bits | radius 2 |
| Extended | "larger radius" | **Morgan radius 2**, 2048 bits | radius 3 |
| PF | path-based | **`PatternFingerprint`**, 2048 bits | `RDKFingerprint` (path) |
| APF | 2048 bits | **4096 bits** (atom-pair generator) | 2048 bits |
| Avalon | "circular" (main text) | hashed substructure, 512 bits | — |
| PCA | "95 % variance" | 95 % **capped at 50 components**: APF 69.1 %, Avalon 81.8 %, PF 87.9 % retained | — |
| RDKit desc. | 211 | 210, hydrogen-explicit | no explicit H |
| Mordred | 1,827; corr. filter | 1,826; **no** correlation filter (only RDKit and MACCS get one) | `ignore_3D=True` |

Changes:

* `CONFIG` and the `compute_*` fallback featurizers now match the cached features: `morgan_radius=1`, `extended_radius=2`, `apf_n_bits=4096` via `rdFingerprintGenerator`, `compute_pattern_fp` using `PatternFingerprint`, RDKit descriptors with `Chem.AddHs`, and Mordred with `ignore_3D=False`. Recomputing Morgan from SMILES with the new fallback reproduces `results/fp_cache/Morgan.npy` exactly.
* The PCA step prints a note whenever the 50-component cap prevents the 95 % target.
* `src/verify_features.py` (new) regenerates each fingerprint from SMILES, checks every cache against its CSV, and reports dimensions, retained variance and distinct-vector counts.
* The notebook has explanatory markdown cells. Its code and outputs are unchanged.

## Major 3: "top-10 %" pool

*Confirmed.* PCE > 12 % is 370 of 1,481 molecules (25.0 %); the 90th percentile is 14.3 %. The label has been replaced by "high-efficiency pool (PCE > 12 %)" in `CONFIG`, in all plot labels (`src/make_figures.py`, movie script), in the regenerated `results/figures/*` and `results/movies/*`, and in the README.

## Major 4: NLPD interpretation

Not a code issue, but the repository now supports the corrected discussion:

* `src/make_figures.py` plots the mean **and median** NLPD over seeds on a log axis (Figure 4), plus per-seed NLPD trajectories (`results/figures/nlpd_per_seed.png`, Figure S2).
* The fitted GPR hyperparameters (constant, length scale, noise level) are now stored for each iteration (`gpr_kernel_params` in `al_results.json`) in future runs, so calibration failures can be diagnosed directly.
* An optional `gpr_random_state` makes reruns bit-reproducible. The default, `null`, reproduces the paper's unseeded optimizer restarts.

## Minor 1: Data merging and deduplication

The README and notebook now document the three-step "keep highest PCE" procedure (944 → 912, 1,558 → 763, 1,675 → 1,481 after canonicalisation). They also state that the label is the best PCE reported for any device containing the molecule.

## Minor 2: Placeholders

`config/benchmark_config.json` (new) is the machine-readable parameter file that the manuscript refers to, and the main script loads it. The README placeholders (`<REPO_URL>`, citation, contact, RAM and runtime) have been replaced. One item still needs the author: the original source of `train_test_combine.csv` (marked **TODO** in the README).

## Other clean-up

* `src/active_learning_benchmark.py` and `src/make_supplementary_movies.py` have been moved to `src/legacy/`. The first still contains the old fallback settings.
* `docs/paper_draft.md` has been removed. It was an outdated draft that repeated the corrected errors ("top-10 %", radius 2, path-based PF), and it remains in git history.
* The machine-specific `prefix:` line has been removed from `environment.yml`.
* `np.trapz` now falls back to `np.trapezoid`, for NumPy 2 compatibility.
