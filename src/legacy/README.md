# Legacy scripts (not used for the paper)

* `active_learning_benchmark.py`: an earlier variant of `../active_learning_benchmark_700dpi.py` whose AL code is identical but which draws a combined two-panel figure. Its fallback featurizers still carry the old, incorrect settings (Morgan radius 2, Extended radius 3, path-based PF, 2048-bit APF) and its plots use the incorrect "top-10 %" label. Use the main script instead.
* `make_supplementary_movies.py`: superseded by `../make_supplementary_movies_revised.py`.
